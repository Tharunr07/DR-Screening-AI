# Manifest Schema — `data/processed/manifest.csv` / `.mat`

> Unified, provenance-preserving index of every fundus image discovered under `data/raw/`.

## File Locations

- `data/processed/manifest.csv` — portable, human & machine readable
- `data/processed/manifest.mat` — MATLAB table `manifest` (same rows, typed)
- Generated by: `matlab/data/generateManifest.m` → `buildManifest.m`
- Config: `matlab/data/datasetConfig.m`

## Column Definitions

| Column | Type | Example | Meaning | Source | Missing Handling |
|--------|------|---------|---------|--------|------------------|
| `image_id` | string | `a3f1c9d2...` or `IDRiD_001` | Basename without extension, unique within dataset | fileparts | Always present (derived) |
| `dataset` | string | `APTOS2019`, `IDRiD`, `DRIVE`, `Messidor2` | Dataset provenance — never merged silently | folder discovery | — |
| `file_path` | string | `data/raw/APTOS2019/train_images/a3f.png` | Path **relative** to project root (portable) | buildManifest | — |
| `file_path_absolute` | string | `C:/dev/SIH/DR_Screening/data/raw/...` | Absolute path for MATLAB `imread` | buildManifest | — |
| `file_format` | string | `PNG`, `JPG`, `TIF` | Uppercase extension without dot | fileparts | `UNKNOWN` |
| `laterality` | string | `LEFT`, `RIGHT`, `UNKNOWN` | Eye side | CSV/ filename heuristic | `UNKNOWN` |
| `patient_id` | string | `12345` or `UNKNOWN` | Patient/subject identifier for leakage grouping | CSV or derived | `UNKNOWN` (never invented) |
| `subject_id` | string | same as patient_id | Alias for compatibility | same | `UNKNOWN` |
| `dr_grade` | double | `0`–`4` or `NaN` | Normalized DR grade (APTOS 0–4 taxonomy) | CSV → numeric | `NaN` |
| `dr_grade_original` | string | `"2"` or `"Moderate"` | Verbatim source label for provenance | CSV | `''` if unavailable |
| `quality_status` | string | `UNKNOWN` | Future quality gate placeholder | — | Always `UNKNOWN` in Phase 1 |
| `has_vessel_annotation` | logical | `true`/`false` | Does a vessel mask exist for this image? | DRIVE mask discovery | `false` |
| `has_lesion_annotation` | logical | `true`/`false` | Does any lesion mask exist? | IDRiD GT discovery | `false` |
| `vessel_mask_path` | string | `.../1st_manual/21_manual1.gif` | Path to vessel GT if any | DRIVE scan | `''` |
| `lesion_annotation_path` | string | `.../EX/IDRiD_001_EX.tif` | Semicolon-joined lesion GT paths | IDRiD scan | `''` |
| `split` | string | `train`, `val`, `test`, `external`, `UNKNOWN` | Leakage-aware assignment | `generateSplits.m` | `UNKNOWN` before splits; `external` for Messidor-2 |
| `width` | double | `640` | Image width (px) from `loadImageSafe` | imfinfo/imread | `NaN` if unreadable |
| `height` | double | `480` | Image height (px) | — | `NaN` |
| `channels` | double | `3` | Channels (1=grayscale, 3=RGB) | — | `NaN` |
| `file_size_bytes` | double | `123456` | File size on disk | dir.bytes | `NaN` |
| `file_hash` | string | `d41d8cd98f...` or `''` | Hex hash if `computeHash=true` | `computeFileHash.m` | `''` |
| `provenance` | string | `APTOS2019`, `DRIVE/mask` | Dataset/subrole tag | buildManifest | — |
| `status` | string | `OK`, `orphan_no_fundus_match` | Row health / mapping notes | buildManifest | — |

## Invariants & Contracts

- **Sort order**: deterministic `(dataset, image_id)` before writing.
- **No invention**: `UNKNOWN` / `NaN` / `''` used wherever source metadata genuinely missing (per spec).
- **Read-only raw**: `buildManifest` never writes under `data/raw/`.
- **Portability**: `file_path` is relative with forward slashes; `file_path_absolute` is absolute for execution.
- **Idempotence**: re-running `generateManifest` with unchanged raw data produces identical `image_id`/`dataset`/`file_path` tuples.
- **Split isolation**: `dataset == "Messidor2"` ⇒ `split == "external"` (enforced at creation + preserved by `generateSplits`).

## Referential Integrity

- Manifest `file_path_absolute` entries should point to existing files — audit reports `missingFiles` where not.
- `has_vessel_annotation = true` ⇒ `vessel_mask_path` non-empty and (if DRIVE present) file exists. Audit verifies.
- `has_lesion_annotation = true` ⇒ `lesion_annotation_path` non-empty.
